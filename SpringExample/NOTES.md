## What is Spring Boot ?
-  Open Source, Java-based framework used to create stand alone, production-grade Spring-based application.

### What is the difference bw Spring & Spring Boot
- `Spring:` Lots of steps involved setting up, configuration, writing boilerplate code, deployment  of the app.
- `Spring Boot:` Offer a set of preconfigured components or defaults and elimination the needs for lot of boilerplate code that was involved in setting up a spring application.
- `Spring Boot Actuator:`
- `Auto-Configuration:`
- `Spring Boot Stater:`
- `Embedded Server:`
- `Spring Boot DevTools:`

### Advantages of Spring Boot
- Stand alone and quick start
- starer code
- less configuration
- reduce cost and application development time

### How does Spring Boot Work (Spring Boot Architecture)
- `Presentation layer:` Presentation layer presents the data and the application features to the user. This is layer where all the controller classes exits.
- `Service layer:` Service layer is where business logic resides in the application. Tasks such as evaluations, decision-making processing of data is done at this layer. This layer interact with both presentation and the data access layer.
- `Data access layer:` Is the layer where all the repository classes reside.
